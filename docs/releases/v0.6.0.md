# v0.6.0 · 全域三维数字孪生与本体联动

以卫星红线全域为默认首页，保留原大屏布局。Blender 可编辑模型覆盖 9 处村落、农田、湖塘、林地、道路及灌排环境；网页加载全域两级 LOD 和五份图纸分片。图中地块、演示设备和预警均可查询持久化本体档案，农业助手支持受控定位、消歧、来源核查和方案草稿。

缺失信息采用明确标记、可替换的样例。原台账 100 个 UUID 保留；真实资料和样例隔离。当前模型仍是简化重建，未完成测绘配准；五份图纸独立使用纸面坐标，未接入真实遥测或现场设备控制。

## 下载与启动

- `farm-v0.6.0-complete.zip`：完整可重建工程，包含源码、资料、公开初始化数据、网页模型、Blender 源、材质及验证记录。
- `farm-v0.6.0-models.zip`：7 个当前网页 GLB 与模型清单，按 `public/models/` 路径恢复。
- `farm-v0.6.0-blender.zip`：正式 `farm-full.blend`、生成纹理、建模和导出检查记录，按 `deliverables/blender/` 路径恢复。
- `SHA256SUMS.txt`：上述三个压缩包的 SHA-256。
- `publication-inventory.json`：Git 源文件范围与内容指纹。

不要把 GitHub 自动生成的 Source code ZIP 当作已含大资产的完整包。使用源码归档或 Git 克隆时执行：

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
npm ci
python scripts/fetch_release_assets.py --all
.venv/Scripts/python.exe scripts/db_init.py
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Production -WithoutModel
```

打开 `http://127.0.0.1:5173`。农业助手需要另外配置模型服务；未配置时界面会明确显示状态。可按 README 安装固定版本 Qwen/llama.cpp 或配置兼容服务，密钥由服务端管理。

完整包不含 `.env`、运行数据库、对话/审计/方案历史、本地工具、模型推理权重、node_modules、虚拟环境和临时工作文件。公开种子仅用于新库，已有库不覆盖；其身份与安全范围见 `../release-data-seed.md`。

## 检查与交付边界

本版场景已完成 16 个实际浏览器视图和全部九处村落复核；原工程验证为 23 个浏览器、33 个 JavaScript/适配、81 个后端检查通过，详见 `../acceptance.md`。发布准备另行验证干净初始化、公开数据范围、离线资产恢复、校验失败和路径安全。最终发布检查回执随本版提供，不将历史软件测试冒充现场或视觉验收。

具体参数与后续替换见 `../user-guide.md`、`../model-methodology.md`、`../backend-full-scene.md`；第三方资产来源和许可边界保留在仓库 `THIRD_PARTY_NOTICES.md`。
