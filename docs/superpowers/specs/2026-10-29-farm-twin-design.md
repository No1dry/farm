# 全区域智慧农业数字孪生设计

依据：用户本次完整实施要求。使用现有 Three.js/Vite 大屏，主体资产改为 Blender 维护与导出；不引入本体仓库前端。当前目录为压缩包工作副本，无 .git，原文件保留，新增模块实现，未进行远程推送。

## 数据与空间

资料原文件不改动。台账提取保留工作表、行号、原编号、原面积和单位；总计、分片区和地块不叠加。图纸和照片保留哈希、来源、版本及位置待核实标记。卫星截图只能提供局部概略坐标，不能冒充测绘坐标；未完成图纸到卫星配准的精细区域独立展示。全域模型覆盖红线，未细化区域明确标注。模型面积与台账面积分列。

本体整合版本必须经源码审查确定。空间ID和业务UUID通过持久映射关联，编号不全局唯一。真实资料与演示记录通过 dataset 隔离，禁止以名称相似自动合并。单机部署采用可迁移持久数据库与参数化查询，保留上游身份与语义契约的可适用部分，差异记录在审查文档。真实观测、鱼种、设备为空时保持为空。

## 应用

保留全屏场景、半透明面板；通过 GLTFLoader 加载 Blender 资产，具备选择高亮、搜索、平滑定位、图层与精度说明。数据库查询承担档案、统计、观测、设备、预警、来源，不使用随机实时数值。

助手采用实体解析 → 档案/关系查询 → 知识检索 → 可配置模型 → 结构校验。前端只接受 allowlist 场景动作，绝不执行模型代码。未配置/不可用模型明确返回状态，结构化数据库查询仍可用，但不标为模型回答。方案须保留证据ID、缺口、条件和时间；无写入SQL/命令/设备控制工具。方案保存需显式用户操作。

## 验证与边界

对持久化、重复导入、歧义、不跨数据集合并、缺失鱼种/设备/知识、过期值和单位冲突进行自动测试。实际构建、启动服务、加载GLB和浏览器检查，性能记录包括机器/视口/三角面/绘制调用/帧时间。模型服务凭据和现场测绘资料缺失作为独立验收限制，不能宣称整体验收通过。
