- 以 `src/focus/main.js` 与 `src/focus/style.css` 中的 V0.2 大屏为界面基线。恢复原顶栏、六个侧边半透明面板、场景工具栏、底部四镜头、照片和资料交互。
- 原 `src/focus/style.css` SHA-256：`874531436ffa156b232ca89766c1acfdd1f715ef22b4b2eba473cb5702a7c1cd`。数据更新可以改变文本，不能借此重排界面。
- 保留已有数据库、审计来源、100 条台账身份、真实与样例隔离。助手仅新增独立浮动入口和对话窗口。
- 不改变原始资料，不把表现高差、塘深、建筑体量、植被、视觉纹理当作测量值或生产事实。

## 三维结果

- 主体使用 Blender 制作的可编辑体积结构和 GLB 导出物；禁止以卫星/CAD 图片平面或图片投影充当主体。
- 全域来源轮廓和 5 份图纸的独立局部轮廓继续保留。来源图仅作为隐藏建模参考或用户主动打开的资料图。
- 田面、田埂、土层侧面、塘岸坡、路面路肩、沟渠槽壁与槽底应可从低角度辨认；近看有真实土壤、碎石、混凝土及水面材质。
- 所有照片位置未确认；它们支持外观表现，不支持把具体设施位置或尺寸确定为现场事实。
- 无准确配准的局部图纸不能伪装已与全域无缝测绘拼接。全域覆盖仍应是真正的几何场景。

## 验收方式

1. 浏览器原大屏与 V0.2 同尺寸截图和布局坐标对比；CSS 哈希一致。
2. Blender 低角度材质渲染和去贴图灰模渲染，确认实体结构不是图片；重新打开源文件确认无外部遗失依赖。
3. 检查网页实际请求 GLB，主场景无卫星/CAD 材质，四镜头与点击、搜索、助手数据库闭环可运行。
4. 全域和五片区均实际打开，记录性能及未解决内容。不能因局部样区好看就宣称全区域验收完成。
