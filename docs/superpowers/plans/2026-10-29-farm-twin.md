# Farm Twin Implementation Plan

> **For agentic workers:** 使用 executing-plans 与独立领域代理执行，按实际证据更新记录。

**Goal:** 将现有样板工程升级为可运行、来源透明的全域资产与数据库助手联动系统。
**Architecture:** Blender 静态主体资产 + Three.js 大屏 + 受控后端查询/助手 + 持久数据库。
**Tech Stack:** Blender Python、Three.js、Vite、Python、SQLite（单机持久化）；上游契约审查后适配。
**Spec:** ../specs/2026-10-29-farm-twin-design.md

## Global Constraints
- 无源数据不填事实；真实/演示隔离；无模型不冒充模型回答。
- 不引入上游前端；不将未配准对象强行关联。
- 用户已指定实施顺序及仅就阻塞问题提问，按该授权持续推进。

## Review Focus
- 同编号跨片区歧义，不跳错对象。
- 缺失/过期/单位冲突，建议必须显示限制。
- 模型服务错误或恶意文本，不执行代码或泄露密钥。
- 模型加载与DB错误不生成假成功。
- 面积层级和资料版本不能重复累计。
