# 全域三维大屏使用与样例替换

打开 **http://127.0.0.1:5173**。默认显示卫星红线全域及“演示业务 · 卫星轮廓”。原来的顶栏、左右六个悬浮面板、照片、工具栏和底部四个视角保留。拖动旋转、滚轮缩放；主体加载 Blender 导出的 GLB，卫星图只在资料窗口中查看。

## 在图中查本体数据

直接点击田块、水塘、村落、林地，或点击图中的设备和预警标记。左侧档案显示独立 UUID、本体类型、面积口径与数据性质，右侧显示数据库观测和“主体 → 关系 → 客体”。点击关联对象可查看其档案；已登记演示位置的关系同时在三维场景中连线。

设备图标和三维器材共用同一个设备 key；它们查询设备自己的 UUID。设备名称、鱼种、作物、观测和规则凡属演示均标明“演示/样例”。刷新页面不会生成随机监测值，也不会把固定观测时间改成当前时间。

默认全域场景有 121 个主对象、49 个演示设备和一个演示管理组。建筑、树木等外观实例不等于经过现场核实的资产数量。原左侧列表显示四个对象以适应原面板，完整对象可以通过场景左上标签打开目录检索。

## 查看真实资料

在档案面板选择“资料”。样例业务标记和器材会隐藏，模型外观仍保留，同时显示来源资料、缺失字段及待确认事项。真实地物与演示业务使用不同 UUID，即使借用同一个轮廓展示，也不会混写种养殖和监测信息。

点击场景左上“卫星红线全域”可切换全域和五个图纸片区。搜索 `庙下刘 L18` 可进入原台账地块。图纸片区仍是独立纸面坐标，尚未具备可靠控制点将其精确拼接到卫星坐标；同名对象不会自动合并。

100 条原台账合计原值 1010.99，但原表没有注明面积单位。界面保留原值与“原表单位未注”，不将其宣称为亩。模型估算面积与台账面积分别显示。

## 农业助手

右下角打开农业助手。在“资料”模式输入 `进入庙下刘片区的 L18 田块，介绍一下这块田`，模型查询数据库后给出档案、来源和受控定位。输入 `进入 E3 田块` 出现多个候选时，先选定对象再继续。

演示模式下搜索真实编号没有结果时，可点击“到真实资料查找”。该操作显式切换数据集，不把演示对象假装成现场地块。

在全域演示模式选中有预警标记的塘，输入 `分析当前演示水塘的预警，核查关联设备、观测和知识依据，给出核查处置方案`。回答展示对象、事实证据、判断边界、处理建议、设备需求、复测跟踪和来源七部分。当前指代保留所选 UUID；输入明确的新编号才解析另一个目标。

模型名称和可用状态显示在对话框中。服务不可用、未配置或结构校验失败会明确报告，不以预设话术冒充模型回答。数据不足、过期、单位冲突和没有知识依据会显示限制。方案只有点击“保存此方案记录”才持久化为草稿；保存不代表执行，系统没有现场设备控制接口。

## 后续替换样例

| 要修改的内容 | 文件及更新方式 |
|---|---|
| 村落、屋顶候选、村路、补充地表和精化水岸 | `data/spatial/full-region-enrichment.json`；保留来源与确认状态，使用原卫星图像素坐标 |
| 建筑高度、树木、田面和水岸等表现参数 | `data/model/full-region-parameters.json`；修改后重新运行 Blender 构建 |
| 样例作物、鱼种、设备属性、观测和预警 | `data/demo/full-area-scenario.json`；可按空间 ID / 设备 key 单独覆盖 |
| 演示设备的位置和类型 | `data/demo/full-area-device-layout.json`；重建 GLB 并刷新样例数据库，不能只移动图标 |
| 经过现场确认的真实数据 | 通过校验后的真实数据导入流程更新 real；不得直接把 synthetic 标识改成 verified |

只更新样例业务时执行 `python scripts/db_refresh_scenario.py --receipt deliverables/verification/full-scene-import.json`。脚本先备份，再核对真实记录未变。同一个 key 重复导入保留 UUID，删除的本场景设备退役，重新加入同 key 可以恢复身份。

模型源文件为 `deliverables/blender/farm-full.blend`，材质已打包。修改几何后须重导出模型、刷新数据库空间绑定并 `npm run build`。完整命令、备份恢复和权限配置见 [README](../README.md)、[运维说明](backend-operations.md) 与 [全域样例契约](backend-full-scene.md)。

全域模型依据卫星轮廓和资料建立，缺失的高度、水深、植被、建筑细节及业务信息采用已标记样例。它仍是简化三维重建，不是实测或照片级成果。实际检查记录与剩余事项见 [交付检查](acceptance.md)。
