# 资料缺口、精度边界与后续核验

现有资料已支持全域概略场景、五份独立图纸、100个台账轮廓与来源检索。2026-10-29 用户明确授权“没有的信息先用样例数据建模，后面再更改”：缺失的外观、尺寸、植被、设施及业务演示现可用可替换样例补齐。下表记录的现场事实仍待核验；样例不改变这些事实的确认状态，也不进入真实生产统计。

| 编号 | 当前状态 | 所需核验 / 输入 | 影响 |
|---|---|---|---|
| G01 | 五图为独立PDF纸面坐标；卫星截图仅有概略比例 | CAD/GIS原始矢量、正式CRS、可复核公共控制点、误差与接边核验 | 尚未完成统一实地配准，不能据图纸拼接位置进行工程测量 |
| G02 | 无连续实测高程、塘深、水位和明确基准 | 地形测量、基准说明、池塘及灌排断面测量 | 高差、岸坡、厚度等仅为表现参数，不做土方或水动力计算 |
| G03 | XLS“种植面积”原表未写单位；施工/平整/种植口径不同 | 台账单位、统计范围及版本差异确认 | 1010.99仅是原值合计，不能直接报亩或与模型面积凑数 |
| G04 | 新屋湾图E3是图外白区标签，A–F图E3是有界田块 | 跨图对应与编号沿革核验 | 已分别保存UUID及候选关系，不擅自合并 |
| G05 | 20个功能设施仅有文字锚点，22条路渠为概化源迹 | 设施实际点位/轮廓、完整资产编号、尺寸、工程分段与在役核验 | 锚点不能冒充泵闸占地；268条设施文字不能统计为268个唯一设施 |
| G06 | 5张现场照片无可靠GPS/拍摄时间 | 照片定位、拍摄日期、与实体对应记录 | 仅作外观参考，不能宣称是某个指定地块的实景 |
| G07 | 真实种养殖、阶段、密度、设备状态及遥测未提供 | 现场台账、传感器/设备映射、接口协议、观测时间/单位/校准和质量记录 | 真实监测保持“未接入”；独立演示实体可引用全域几何作为明确标注的演示位置，UUID/业务关系/监测与真实数据分离 |
| G08 | 4条公开参考有适用条件，但不是现场批准规则 | 鱼种/作物、季节、阶段、环境、装备能力与适用阈值的专业确认 | 不能输出无依据的生产剂量、时长、采购数量或效果承诺 |
| G09 | 全部PDF原图保留，100田块矢量与268条原生设施文字已整理；CAD轮廓字未声称全量语义OCR | 后续逐设施核查时结合原图、CAD和现场清单消歧 | 当前设施档案与几何覆盖边界以实际清单为准，不宣称完成全部现场设施调查 |
| G10 | 本机回环部署、操作员会话和管理员Bearer权限已验证 | 实际部署域名/TLS、账号体系、运行环境、备份策略及目标硬件测试 | 不把本机性能或单用户权限当作公网生产运维验收 |

资料更新应先保存原文件与旧指纹，再修改来源台账、核对冲突、更新Blender表示并受控导入。业务UUID随数据库备份迁移；几何调整、退役、恢复或解开错误关联均保留审计。禁止为对齐总面积修改边界，禁止按同名将演示鱼种、设备或监测写入真实实体。
