## 运行验证证据

本次最终统一运行：Python **25/25**，前端契约 **4/4**，Chrome端到端 **8/8**；`npm run build`成功。共37个测试场景通过不等于七项整体目标全部验收。活动数据库为100条台账、133个空间绑定、230条资料实体记录及14条演示实体；误分湖汊另有1条退役历史记录。

最终本机采样：全域GLB加载432.5ms，300帧间隔中位数7.0ms、P95 7.3ms；408次绘制、95,786个可见三角面。全域GLB 21,028,216字节、局部12,385,688字节。以上仅是该次运行条件下的记录。

最终运行的测试结果见 `deliverables/verification/backend-junit.xml`、`browser-tests.json`；前端契约测试为 `npm test`。Blender独立重开证据见 `deliverables/blender/verification.json`。构建有Three.js公共包超过500kB的提示；Python测试有Starlette/httpx测试客户端弃用提示，均保留记录。

浏览器使用本机Windows/Chrome无头模式、1600×1000、DPR=1。`browser-performance.json`记录GLB加载时间、实际渲染三角面、draw calls、帧间隔中位数/P95及采样数量。帧间隔不是GPU耗时，回环网络不代表远程下载，不能据此保证工控机或手机帧率。资产按全域/局部延迟加载；尚无多级LOD、KTX2或广域分区流式加载。

`full-area.png`、`parcel-assistant.png`、`demo-warning-inspection.png`、`narrow-layout.png`是实际自动化运行截图，辅助视觉复核；功能验收依据是浏览器点击/响应/状态断言。`artifact-hashes.json`将测试记录与交付文件对应。水域曾被底面遮挡的问题已通过地形开孔、面积核对和独立射线检查修正，旧截图不作为最终资产依据。
