# 铜铁海智慧农场 · 庙下刘重点片区

当前首页为 V0.2 可交互三维可视化大屏，聚焦竣工图东侧的 L18、L19、L20 农田及“清-17”水塘。界面采用半透明悬浮数据面板，中央为真实 WebGL 三维场景；场景使用写实 PBR 材质、自然天空、水面反射，以及有孔洞的沟渠护坡几何。

## 查看

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ ，浏览器需支持 WebGL 2。

底部四个入口：片区总览、农田近景、沟渠细节、水塘岸线。拖动可旋转，滚轮可缩放。点击农田或左侧单元选择区域，档案中的按钮进入对应近景。

右侧现场影像支持切换和放大五张用户照片。资料按钮可查看竣工图、参考照片和精度说明。图层按钮可控制设施、草叶和区域标注。窄窗口通过“地块”“数据”按钮打开面板，右上角支持全屏（取决于宿主浏览器）。

## 范围与精度

- 轮廓根据旋正的竣工图局部人工描绘；使用局部展示坐标，未完成 CAD/地理坐标配准。
- 仅建立 3 个农田单元、1 个水塘单元。非全农场模型。
- 几何尺寸、沟渠深度、田埂高度、水位、植被、辅助建筑外观为表现参数，尚未以测绘数据校核。
- 现场照片用于护坡、土壤、道路和岸线外观参考，尚未把拍摄位置与图纸田块一一对应。
- 地块作物、养殖用途、实际面积、土壤及水质监测尚未确认或接入；界面以“待确认”“待补充”“未关联”或破折号展示。
- 262.79 亩、151.45 亩是整张竣工图所标注的施工面积和平整田块面积，不能当成本次样板区面积。
- 223.18 m、392 m、37 kW 为竣工图中的工程档案标注，不代表实时监测或模型量测结果。
- 水面波纹是视觉动画，无水动力计算；太阳能闸、泵站和电杆为参考模型，无真实控制接口。
- 天空和背景田块属于视觉环境参考，不代表现场天气或测绘成果。

## 源文件

- `src/focus/data.js`：L18/L19/L20、水塘、道路、沟渠及设施的局部轮廓、属性与资料出处。
- `src/focus/model.js`：田块、开口地面、沟渠断面、孔洞护坡、植被、道路、设施的三维几何及材质。
- `src/focus/main.js`：WebGL 初始化、四个视角、选择、图层、照片、资料与响应式交互。
- `src/focus/style.css`：大屏透明面板与布局。
- `public/focus/photos/`：五张用户现场照片。
- `public/focus/as-built.png`：用户竣工图的旋正渲染图。
- `public/focus/textures/`：本地 PBR 贴图、水面法线和天空 HDRI。
- `public/focus/ASSET-SOURCES.md`：第三方材质的来源与授权信息。

没有外部 CDN 运行依赖；纹理与照片均随本地项目加载。

## 构建

```sh
npm run build
npm run preview
```

`dist/` 可由静态 HTTP 服务运行。请不要直接使用 file:// 打开。

V0.1 总体轮廓原型保留在 `/overview-v01.html`，其 GLB 文件与数据说明见 `README-v01.md`；它不是当前重点片区的模型。
